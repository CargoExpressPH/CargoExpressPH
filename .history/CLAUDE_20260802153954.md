# CargoExpress PH

## Stack
- React Native (Expo)
- Node.js (Express)
- MySQL
- Firebase Authentication
- Firebase Firestore

## Business

Door-to-door cargo delivery.

Routes:

- Manila → Bohol
- Bohol → Manila

Users:

- Customer
- Admin

Rules:

- One active trip at a time.
- Van capacity is measured in kilograms.
- Bookings can exist without an assigned trip.
- Admin assigns bookings to trips.
